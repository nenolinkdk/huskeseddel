# Huskeseddel

En enkel Android-app fra Nenolink til at oprette og bruge indkøbslister.

## Formål

Appen skal gøre det hurtigt at vælge dagligvarer fra faste kategorier, generere en aktuel huskeseddel og krydse varer af under indkøbet.

Første version skal være enkel, offline og uden login eller backend.

## V1-funktioner

- Varer opdelt i kategorier
- Afkrydsning af varer før indkøb
- Automatisk genereret huskeseddel
- Mulighed for at markere varer som købt
- Kort note til den aktuelle liste
- Tilføj egne varer
- Rediger/slet egne varer
- Lokal lagring på telefonen
- Søgning i varer
- Sammenklappelige kategorier
- Nyt indkøb / ryd købte
- Dansk som første sprog

## Produktretning

Huskeseddel er tænkt som et lille Nenolink-produkt, som senere kan distribueres via Nenolink.com og eventuelt Google Play.

En QR-kode på produktsiden bør pege på produktsiden eller den officielle downloadside, ikke direkte på en versionsspecifik APK.
