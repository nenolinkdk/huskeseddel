# UI-flow - Huskeseddel v1.0

## Navigation

Tre hovedområder:

1. Varer
2. Huskeseddel
3. Indstillinger

Kan implementeres med bottom navigation.

## Skærm: Varer

Elementer:
- søgefelt
- kategorier som expandable sections
- checkbox pr. vare
- knap til "Tilføj vare"

Interaktion:
- markering tilføjer varen til aktiv huskeseddel
- fjern markering fjerner varen fra aktiv huskeseddel

## Skærm: Huskeseddel

Viser kun valgte varer.

Elementer:
- varer grupperet efter kategori
- checkbox eller status for "købt"
- valgfrit antal
- note
- "Ryd købte"
- "Nyt indkøb"

## Dialog/skærm: Tilføj vare

Felter:
- varenavn
- kategori

Handlinger:
- Gem
- Annuller

Ved redigering:
- Ret navn
- Flyt kategori
- Slet

## Skærm: Indstillinger

V1:
- Om Huskeseddel
- Version
- Nenolink
- Privatliv / data: "Alle data gemmes lokalt på enheden"

## UX-principper

- få tryk
- store trykflader
- tydelig tilstand
- ingen unødvendige popups
- ingen login
